# Sentio

Sentio is a next-gen crypto data platform for real-time indexing, analytics, and alerting across modern blockchains. With intuitive UX, powerful APIs, and deep multi-chain support, Sentio helps teams ship faster and operate smarter.

Sentio supports both **Sentio Processor** and **Subgraph** as indexing options.

## Cronos support

Sentio supports Cronos Mainnet for real-time data indexing and analytics.  
For more details, visit the official documentation:  
https://docs.sentio.xyz/docs/supported-network#cronos
